Node.js
It is a JavaScript runtime that lets you run JavaScript outside the browser—commonly for backend servers, APIs, command-line tools, and real-time applications.

module.exports
It is used to export functions, variables, objects, or classes from one Node.js file (module) so they can be used in another file.
Think of it as:

module.exports → send something out of a file
require() → bring it into another file

Example

math.js

const add = (a, b) => {
    return a + b;
};
module.exports = add;

app.js

const add = require("./math");
console.log(add(5, 3));

Output:
8

Exporting multiple things

math.js

const add = (a, b) => a + b;
const sub = (a, b) => a - b;
module.exports = {
    add,
    sub
};

app.js

const math = require("./math");
console.log(math.add(10, 5));
console.log(math.sub(10, 5));

Output:
15
5

Export in Directories

A common structure is:

project/
│
├── app.js
│
└── math/
    ├── add.js
    ├── sub.js
    └── index.js

1. add.js
function add(a, b) {
    return a + b;
}
module.exports = add;

2. sub.js
function sub(a, b) {
    return a - b;
}
module.exports = sub;

3. index.js
The index.js file can collect and export the modules:

const add = require("./add");
const sub = require("./sub");

module.exports = {
    add,
    sub
};

4. app.js

Now you can import the directory:

const math = require("./math");
console.log(math.add(10, 5));
console.log(math.sub(10, 5));

Output:
15
5

NPM (Node Package Manager)
It is the default package manager for Node.js and is used to install, manage, update, and share packages (libraries).

Installing Packages 

Step 1: Create a project

mkdir figlet-demo
cd figlet-demo
npm init -y  // npm init -y is used to quickly create a package.json file for a Node.js project using the default settings

Step 2: Install the package

npm install figlet

After installation, NPM creates:
figlet-demo/
│
├── node_modules/
├── package-lock.json
├── package.json
└── app.js

Step 3: Use figlet

Create app.js:
const figlet = require("figlet");
figlet("Hello", (err, data) => {
    if (err) {
        console.log("Something went wrong");
        return;
    }
    console.log(data);
});

Step 4: Run the program
node app.js

You will get large ASCII-art text such as:
 _   _      _ _
| | | | ___| | | ___
| |_| |/ _ \ | |/ _ \
|  _  |  __/ | | (_) |
|_| |_|\___|_|_|\___/

node_modules: It is a folder created by NPM where the packages installed for your project are stored.
package-lock.json: It s a file automatically created by NPM when you install packages. It records the exact versions of the packages and their dependencies installed in your project.

package.json: It is the main configuration file of a Node.js project. It contains information about the project, its dependencies, and the commands (scripts) used to run it.

Creating package.json

Run:
npm init -y

This creates:
package.json

Global Packages
A global package is an NPM package installed on your computer so that it can be used from the command line across different projects.

Install a package globally
Use the -g option:

npm install -g nodemon

Here:
npm install → installs a package
-g → means global
nodemon → package name

Install:
npm install -g nodemon

Then you can use it from any project:
nodemon app.js
You don't need to install nodemon separately inside every project.

Local	                                Global
npm install figlet	                    npm install -g nodemon
Installed for one project	            Available system-wide
Stored in project's node_modules	    Stored in NPM's global package location
Usually used by application code	    Usually used as a command-line tool

Import: It is used to bring functions, variables, classes, or objects from one module into another. It is the modern JavaScript module system, called ES Modules (ESM).

1. Export a function

math.js

export function add(a, b) {
    return a + b;
}

2. Import the function

app.js

import { add } from "./math.js";
console.log(add(5, 3));

Using import in Node.js
You can tell Node.js to use ES Modules by adding this to package.json:
{
  "type": "module"
}

Output:
8
