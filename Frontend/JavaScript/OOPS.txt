OOPs:
OOP (Object-Oriented Programming) is a programming approach where we organize code around objects.
An object contains:

# Properties → data/state
# Methods → functions/behavior

Prototypes: An object from which another object can inherit properties and methods. 

new Operator:
The new operator is used to create a new object from a constructor function or class.

For example:

class Student {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }
}

const student1 = new Student("Kushagra", 20);
console.log(student1.name);

Output:
Kushagra

# Classes:
A class is a blueprint for creating objects. It allows us to combine data (properties) and behavior (methods) in one structure.
JavaScript classes are built on top of the prototype system.

Basic Class: 
class Student {
    constructor(name, age) {
        this.name = name;
        this.age = age;
    }

    study() {
        console.log(this.name + " is studying");
    }
}

Here:

Student → class
constructor() → initializes the object
this.name, this.age → properties
study() → method
Creating Objects

We use the new operator:

const s1 = new Student("Kushagra", 20);
const s2 = new Student("Rahul", 21);

console.log(s1.name);
s1.study();

Output:

Kushagra
Kushagra is studying

# Inheritance:
A class can inherit from another class using extends.

class Animal {
    eat() {
        console.log("Eating...");
    }
}

class Dog extends Animal {
    bark() {
        console.log("Barking...");
    }
}

const dog = new Dog();

dog.eat();
dog.bark();

Output:

Eating...
Barking...

# super: 

super is used to call the parent class's constructor or methods.

class Animal {
    constructor(name) {
        this.name = name;
    }

    eat() {
        console.log("Eating...");
    }
}

class Dog extends Animal {
    constructor(name, breed) {
        super(name);
        this.breed = breed;
    }

    bark() {
        console.log(this.name + " is barking");
    }
}

const dog = new Dog("Bruno", "Labrador");

dog.eat();
dog.bark();
